# Tic-Tac-Toe ออนไลน์

เกมใช้ `main.py` เป็น client และ `server.py` เป็นเซิร์ฟเวอร์จับคู่ผู้เล่น โดย
เซิร์ฟเวอร์จะเป็นผู้ตรวจสอบตาเดินและส่งสถานะกระดานให้ผู้เล่นทั้งสองคน

## รันเซิร์ฟเวอร์

บนเครื่องที่จะทำหน้าที่เป็นเซิร์ฟเวอร์:

```powershell
python server.py --host 0.0.0.0 --port 5000
```

เซิร์ฟเวอร์ใช้ standard library จึงไม่ต้องติดตั้งแพ็กเกจเพิ่ม
เปิด TCP port `5000` ใน firewall ของเครื่องเซิร์ฟเวอร์และเราเตอร์ หากผู้เล่น
เชื่อมต่อผ่านอินเทอร์เน็ต ให้ใช้ public IP หรือชื่อโดเมนของเซิร์ฟเวอร์

## รันผู้เล่น

ติดตั้ง dependencies ของโปรเจกต์ก่อน หากยังไม่ได้ติดตั้ง:

```powershell
uv sync
```

จากนั้นให้ผู้เล่นแต่ละคนรัน client โดยระบุ IP/ชื่อโดเมนของเซิร์ฟเวอร์:

```powershell
uv run python main.py --server 127.0.0.1 --port 5000
```

แทน `127.0.0.1` ด้วย IP หรือชื่อโดเมนของเซิร์ฟเวอร์เมื่อเล่นจากเครื่องอื่น
ผู้เล่นสองคนที่เชื่อมต่อพร้อมกันจะถูกจับคู่โดยอัตโนมัติ กด `R` เพื่อเริ่มเกมใหม่
หลังจบเกม

หากไม่ระบุ `--server` เกมจะเล่นในเครื่องเดียวเหมือนเดิม
